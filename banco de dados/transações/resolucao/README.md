# Resolução - Transações

Execute os arquivos na ordem:

1. `01_tabelas.sql`
2. `02_dados.sql`
3. `03_transferencia_commit.sql`
4. `04_transferencia_rollback.sql`

Após a transferência com `COMMIT`, Ana fica com R$ 1.200,00 e Carlos com R$ 1.100,00. A segunda transferência é desfeita pelo `ROLLBACK`, mantendo esses saldos.
